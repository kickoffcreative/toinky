## Notes

- `simulations.plot_version_id` / `content_checksum` (migration 130) pin the content version a run was created from; `plots.published_plot_version_id` is the published pointer. A NULL `plot_version_id` means a legacy unpinned simulation that reads live tables.
- `games.simulation_id` is UNIQUE with FK `ON DELETE CASCADE` (one game per simulation; deleting the simulation deletes the game). `simulation_review_batch_runs.simulation_id` is NULLABLE with FK `ON DELETE SET NULL` (deleting the simulation nulls the review link but keeps `result_json`).
- `decisions.status` is `ENUM('OPEN','CHOSEN','NO_ACTION','CLOSED')`; the atomic claim (Task 2) is `SELECT ... FOR UPDATE` + conditional `UPDATE ... AND status="OPEN"` + `rowCount()===1`.
- `ai_reasoner_interactions` holds the three MEDIUMTEXT payload columns (`request_json`, `response_json`, `parsed_response_json`); retention is in `tools/prune_ai_logs.php` and migration 132 (`store_raw_payloads='0'`).
- `schema.sql` is a stale partial copy (15 tables) — do not use it as the schema reference; use the migrations plus this dictionary.
