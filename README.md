# Game2 Story Engine Lab

A clean-room prototype for Toinky's story engine.

## Core Principle

One shared reality. Different personal stories.

## First Milestone

- Single simulation page only
- Seven chronological columns: World, Player 1-3, NPC 1-3
- Maximum three NPCs
- Plot-specific story factors
- Character-specific knowledge, location, relationships, stats, decisions and consequences
- Separate authoritative world timeline
- Manual and real-time simulation modes
- Plot 001: Bellweather / Concealed Failure

## Architecture Goal

New plots should be added as structured data rather than story-specific PHP logic.
